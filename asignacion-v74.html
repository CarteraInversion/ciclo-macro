Metodología y precauciones

El Radar y esta página usan clasificador-v74.js y data.json. La clasificación proxy conserva la lógica de fases V6; V7.4 sustituye las ponderaciones, no el clasificador. La paridad histórica exacta con las 235 señales aún requiere auditoría. Se usan datos macro revisados y retrasos aproximados de publicación, no vintages ALFRED. El spread Baa–Treasury no equivale a CCC. La página no ejecuta órdenes. El resultado histórico V7.4 (CAGR simulado 15,45 %) se ajustó tras examinar datos históricos y no es una rentabilidad futura esperada.

La fase explorada manualmente solo sirve para examinar asignaciones; no altera la fase calculada ni el funcionamiento de GitHub Actions.
