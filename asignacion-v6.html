Importes objetivo orientativos. No descuentan comisiones, cambios EUR/USD, fiscalidad ni redondeo a participaciones enteras.

Metodología y precauciones

Esta página y el Radar utilizan clasificador-v6.js y data.json, replicando las reglas del clasificador proxy del backtest V6. Se usan datos macro revisados y retrasos aproximados de publicación, no vintages ALFRED. El spread Baa–Treasury no equivale a CCC. La página no ejecuta órdenes. El resultado histórico V6 (CAGR simulado 15,45 %) se ajustó tras examinar datos históricos y no es una rentabilidad futura esperada.

La fase explorada manualmente solo sirve para examinar asignaciones; no altera la fase calculada ni el funcionamiento de GitHub Actions.
